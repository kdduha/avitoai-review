# Задание 1. Boilerplate сервиса и веб-сервер

Курс: Разработка микросервисов на Go

## Что нужно сделать

1. Создайте репозиторий сервиса `service-courier`.
2. Разделите код на логические директории (cmd/, internal/, pkg/).
3. Поднимите HTTP-сервер. Параметры сервера читаются из `.env`, значения должны
   переопределяться флагами командной строки:

       go run cmd/main.go --port 3000

4. Реализуйте два тестовых эндпоинта:
   - `GET /ping` — отвечает `200` и телом `{"message":"pong"}`;
   - `HEAD /healthcheck` — отвечает `204` без тела.
5. Обеспечьте корректное завершение работы по сигналам SIGINT и SIGTERM. При
   завершении сервис пишет в лог сообщение `Shutting down service-courier`.
6. Добавьте `.env.example` с перечнем переменных. Сам `.env` в репозиторий не
   коммитьте.

## Требования к сдаче

Работа сдаётся ссылкой на pull request. Досдача в течение одного дня после
дедлайна — минус один балл, позже работа не принимается.
