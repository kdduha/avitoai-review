# Демонстрационные данные

Что лежит в репозитории для показа, откуда взято и чему верить.

Общее правило: **данные настоящие, инсценировка наша, и разница подписана.** Код
студентов не менялся; то, что мы разложили или собрали сами, названо здесь и в
описаниях pull request'ов.

## Учебные pull request'ы

Семь черновых PR с решениями студентов из публичного репозитория организаторов
`ai-talent-hub-avito/homework_examples`, папки `GO/… решение 1-3`. Вставляются
ссылкой в «Проверить работу». **Они не вливаются.**

| Решение | ДЗ 1 | ДЗ 2 | ДЗ 3 |
|---|---|---|---|
| хорошее | #25 | #26 | #27 |
| слабое | #21 | #22 | #23 |
| среднее | #24 | — | — |

Семь PR, а не девять: **среднее решение содержит только каркас** — ни базы, ни
слоёв. Задания 2 и 3 этим студентом не сданы, и PR за него мы не придумывали:
отсутствие сдачи тоже состояние.

Четыре решения при сборке и цена каждого:

**База — пустая ветка `demo/base`.** Против `main` диффом стало бы удаление всего
проекта: 269 файлов и полсотни тысяч строк.

**Решение лежит в корне ветки.** Гейт ищет `cmd/` и `internal/` в корне сдачи.
Первая раскладка была в `demo/go/<уровень>/`, и гейт сообщал «не найдено: cmd/,
internal/» — про нашу папку, а не про работу студента.

**Сдача накопительная.** PR по ДЗ 2 содержит и код ДЗ 1: рубрика судит сервис
целиком, спрашивая про `.env`, `main.go` и эндпоинты, появившиеся раньше. Пока PR
содержали только дельту своего этапа, «хорошее» решение получало 1 из 7 там, где
заслуживает 7 из 7.

**Этапы восстановлены по условиям заданий.** Организаторы опубликовали только
итоговый снимок репозитория. CRUD-хендлеры отнесены к ДЗ 2 — это его требование;
ДЗ 3 про слои и интерфейсы, то есть про рефакторинг уже написанного.

## Чему в этих PR верить, а чему нет

Разбор по критериям настоящий: цитаты сверяются с текстом файлов, балл считает
агрегатор.

**Сигналу ГенИИ верить нельзя.** У всех семи он равен `0.40`, и это арифметика:

| Сигнал | Вес | Балл |
|---|---|---|
| форензика истории | 0.35 | 0.80 |
| стилометрия | 0.15 | 0.05 |
| перплексия | 0.25 | не настроена |
| модель-судья | 0.25 | 0.05 |

`(0.8×0.35 + 0.05×0.15 + 0.05×0.25) / 0.75 = 0.40` — ровно, на каждой работе.

Форензика даёт 0.80 всем, потому что **каждая ветка собрана одним коммитом**:
истории у опубликованного снимка нет. Стилометрия и модель-судья при этом дают
разные спаны по разным работам.

Чтобы сигнал начал различать работы, ветки надо собирать несколькими коммитами с
разными датами — но это уже придуманный ритм работы студента (см.
[todo.md](todo.md)).

## Показательная сдача с зачётом

`backend/scripts/seed_demo_submission.py` заводит одну утверждённую работу с
баллом 10 из 10 и отзывом.

```bash
docker compose exec backend uv run python scripts/seed_demo_submission.py
```

Черновик там **настоящий**: проходит тот же гейт, ту же сверку цитат и тот же
агрегатор, что живой прогон. Записаны только ответы модели, и цитаты в них взяты
из настоящих строк файлов записанной сдачи
(`backend/scripts/fixtures/go-task1-pr42.json`). Готовый черновик, вписанный в
базу как есть, разошёлся бы с кодом при первой правке рубрики.

Сдача назначается сеяному `reviewer` — под этим логином ходит переключатель
ролей. Назначенная на карточку каталога, она была видна только руководителю:
чужую сдачу `_load` отдаёт как 404.

Скрипт идемпотентен по `origin_url` и заодно заводит курс, поток, задание и
зачисление, если их ещё нет.

## Записанные прогоны фронта

Шесть разборов в `frontend/src/mocks/demo*.ts` открываются без бэкенда и лежат в
формате ответов сервера, проходя через тот же адаптер, что живой прогон.
Целостность проверяет `npm run check:runs`.

| Прогон | Работа | Зачем |
|---|---|---|
| `demo` | сервис на Go | провал дословного формального требования |
| `demo-sysdesign` | Markdown с C4 | дробная шкала на 6, работа ровно на пороге |
| `demo-backend` | FastAPI и тесты | градация 0.5, штраф за просрочку |
| `demo-qa` | **настоящая** таблица тест-кейсов | шкала на 20, порога зачёта нет вовсе |
| `demo-fraud` | **настоящая** карта рисков | необъявленный ИИ: сигнал есть, декларации нет |
| `demo-go-weak` | **настоящий** слабый репозиторий | зачёта нет при сумме выше порога |

Три последних собраны из настоящих студенческих работ — код, таблица и документ
взяты без правок, вместе с опечатками.

Записанный разбор есть у пяти рубрик из пятнадцати, и `demoRunForRubric`
(`frontend/src/lib/runs.ts`) ищет строго по рубрике: для остальных кнопки
«Открыть демо-прогон» нет, а экран говорит, у скольких рубрик разбор есть. Раньше
при промахе подставлялся разбор по Go — правдоподобно и неверно.

## Каталог программ

`frontend/src/mocks/programs.ts` — пять направлений из девяти, те, у которых есть
записанный разбор: Go, системный дизайн, основы backend, Tech QA, антифрод.
Открыть курс и не суметь провалиться внутрь задания хуже, чем не показать курс.

Ведомость собирается скриптом (`npm run check:roster` сверяет), и девять её строк
лежат дословно из таблицы организаторов — вместе с настоящей опечаткой и пятью
написаниями «Согласие на оценку». Подробности — в `handover-frontend.md`.
