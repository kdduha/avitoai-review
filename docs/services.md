# AI-слой: ревью-агент и детектор

Живёт в `backend/src/avito_reviewer/ai/`. На вход — `SubmissionBundle` от `ingest`
и рубрика; на выход — черновик ревью с проверяемыми цитатами и рекомендательный
отчёт о признаках генерации.

```
SubmissionBundle + Rubric
        │
        ├──→ ai/content.py ─────→ тексты артефактов
        │      excerpt | дозагрузка по content_ref | дифф
        │      неполные помечены partial
        │
        ├──→ ai/review/ ────────→ ReviewDraft
        │      промпт из рубрики        баллы по критериям,
        │      цитаты обязательны       цитаты, фидбек студенту
        │      балл считает код
        │
        └──→ ai/detection/ ─────→ DetectionReport
               4 сигнала                 score + доверительный интервал,
               форензика без модели      спаны с обоснованием,
                                         рекомендательный статус
```

К моделям оба ходят только через `PrivacyGateway` — единственную точку выхода наружу.

## Четыре правила, на которых всё держится

**Модель не ставит оценку.** Она оценивает отдельный критерий и обязана приложить
цитату. Итоговый балл считает арифметика в `review/aggregate.py`: сумма с весами,
округление по шагу шкалы, порог зачёта, обязательные минимумы, штраф за просрочку.
Модель к этому не допускается.

**Цитата проверяется программно.** Ссылка на файл и строки сверяется с содержимым
артефакта. Не совпало — вердикт помечается как требующий человека, а не подаётся
ревьюеру как готовый. Это отсекает основную массу галлюцинаций.

**Сигнал ГенИИ ничего не решает.** По условиям курсов он рекомендательный и на балл
не влияет: детектор возвращает спаны с обоснованием и доверительный интервал, а
решение принимает ревьюер. Интересно при этом не «сгенерировано или нет», а
расхождение между заявленным и найденным: использовать ИИ курсом не запрещено,
запрещено не указывать это.

**Чего мы не видели — то не «отсутствует».** Полного текста файла в сдаче может не
быть: ingest инлайнит `excerpt` только в пределах бюджета, крупные файлы едут
diff-only. Такой файл помечен `partial`, и это тянется через весь слой — промпт,
цитаты, статистические сигналы, черновик. Вердикт «в работе нет обработки ошибок»,
сделанный по одному ханку, — некорректный вердикт.

## Состояние

| Модуль | Готовность |
|---|---|
| `ai/llm/` — шлюз, провайдеры, маршрутизация, аудит стоимости | есть |
| `ai/content.py` — тексты артефактов, резолвер `content_ref`, флаг `partial` | есть |
| `ai/rubric.py` — схема рубрики, разбор JSON, реестр каталога | есть |
| `ai/review/` — промпт, схема, валидатор цитат, агрегатор | есть |
| `ai/detection/` — форензика, стилометрия, judge, ансамбль | есть |
| Перплексия на локальной модели | ждёт сервинга с logprobs |
| Полноценный скрабер ПДн | базовые регулярки; NER на локальной модели впереди |
| Калибровка порогов детектора | не сделана: нужны вердикты ревьюеров |
| Format Gate | есть по git-каналу: пути, строки в коде, объём, история ревизий |
| Format Gate вне git | шрифт, число страниц и тест-кейсов ждут docx-канала |

## Быстрый старт

```bash
cd backend
uv sync --group dev
uv run pytest                 # тесты идут на фейковом провайдере, ключи не нужны
```

Прогон на реальных работах из репозитория примеров:

```bash
uv run python scripts/demo.py review     # записанный бандл, ключей не нужно
uv run python scripts/demo.py detect

git clone https://github.com/ai-talent-hub-avito/homework_examples.git
uv run python scripts/demo.py --repo "homework_examples/GO/Хорошее решение 1-3" review
```

Без ключа демо работает на записанных ответах, собранных из настоящих строк работы,
с ключом — на живой модели.

## Конфигурация

```bash
export AI_LLM__PROVIDER=external          # fake | local | external
export AI_LLM__BASE_URL=https://api.aitunnel.ru/v1
export AI_LLM__MODEL=deepseek-v4-flash
export AI_LLM__API_KEY=...
export AI_LLM__LOCAL_BASE_URL=http://localhost:11434/v1   # vLLM или Ollama
export AI_LLM__FORCE_LOCAL=true           # аварийный тумблер: наружу не ходим вовсе
```

Удобнее — `backend/.env` (шаблон в `.env.example`, файл под gitignore). Тесты
его намеренно не читают: прогон не должен зависеть от того, что лежит в рабочей
копии.

Локальный и внешний маршруты — один и тот же OpenAI-совместимый клиент, отличаются
только `base_url`, моделью и ключом. Переключение целиком на локальный контур — одна переменная
окружения, и это можно показать на демо, не трогая код.
