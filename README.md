# avitoai-review

Ревью-агент и детектор признаков ГенИИ для AI-помощника ревьюера Авито.

Нормализация сдачи и Format Gate живут отдельно (`reviewer-core`, у второго разработчика). Этот репозиторий начинается там, где заканчивается ядро: на вход приходит нормализованный `SubmissionBundle` и рубрика, на выход — черновик ревью с проверяемыми цитатами и рекомендательный отчёт о признаках генерации.

```
SubmissionBundle + Rubric
        │
        ├──→ Review Service ────→ ReviewDraft
        │      промпт из рубрики        баллы по критериям,
        │      цитаты обязательны       цитаты, фидбек студенту
        │      балл считает код
        │
        └──→ Detection Service ─→ DetectionReport
               4 сигнала                 score + доверительный интервал,
               форензика без модели      спаны с обоснованием,
                                         рекомендательный статус
```

Оба сервиса ходят к моделям только через `PrivacyGateway` — единственную точку выхода наружу.

## Три правила, на которых всё держится

**Модель не ставит оценку.** Она оценивает отдельный критерий и обязана приложить цитату. Итоговый балл считает арифметика в `aggregate.py`: сумма с весами, округление по шагу шкалы, порог зачёта, штраф за просрочку. Модель к этому не допускается.

**Цитата проверяется программно.** Ссылка на файл и строки сверяется с содержимым артефакта. Не совпало — вердикт помечается как требующий человека, а не подаётся ревьюеру как готовый. Это отсекает основную массу галлюцинаций.

**Сигнал ГенИИ ничего не решает.** По условиям курсов он рекомендательный и на балл не влияет: детектор возвращает спаны с обоснованием и доверительный интервал, а решение принимает ревьюер.

## Состояние

| Модуль | Готовность |
|---|---|
| `llm/` — шлюз, провайдеры, маршрутизация, аудит | есть |
| `review_service/` — промпт, схема, валидатор цитат, агрегатор | есть |
| `detection_service/` — форензика, стилометрия, judge, ансамбль | есть |
| Перплексия на локальной модели | опционально, включается конфигом |
| Полноценный скрабер ПДн | заглушка: базовые регулярки, полный модуль отдельно |

## Быстрый старт

```bash
pip install -e ".[dev]"
pytest                      # тесты идут на фейковом провайдере, ключи не нужны
```

Прогон на реальных работах из репозитория примеров:

```bash
python scripts/demo_review.py --solution "homework_examples/GO/Хорошее решение 1-3" \
                              --rubric rubrics/go-task1.json
```

Без ключа демо работает на записанных ответах (`--provider fake`), с ключом — на живой модели.

## Конфигурация

```bash
export AVITOAI_PROVIDER=openrouter          # local | openrouter | fake
export AVITOAI_API_KEY=...                  # для openrouter
export AVITOAI_MODEL=openai/gpt-4o-mini
export AVITOAI_LOCAL_BASE_URL=http://localhost:8000/v1   # vLLM или Ollama
```

Локальный и внешний маршруты — один и тот же OpenAI-совместимый клиент, отличаются только `base_url`. Переключение целиком на локальный контур — одна переменная окружения.
