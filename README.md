# Демонстрационные сдачи

Пустая база для учебных pull request'ов. Против неё открыты PR с решениями
студентов из публичного репозитория организаторов — их вставляют ссылкой в
«Проверить работу» и прогоняют через разбор.

База пустая намеренно: решение в PR лежит в корне, как в репозитории студента.
Гейт ищет `cmd/` и `internal/` в корне сдачи, а против `main` диффом стало бы
удаление всего проекта.

Эти ветки не вливаются.
