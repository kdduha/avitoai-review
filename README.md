# Avito AI Reviewer

Рабочее место ревьюера образовательных программ Авито: одна вкладка вместо
GitHub + Google Docs + Sheets. Полная архитектура — `.claude/architecture.md`.

## Запуск

```bash
docker compose up --build
```

- API — http://localhost:8000
- Swagger — http://localhost:8000/docs

Ключей для старта не нужно: без них LLM-слой работает на провайдере `fake`. Весь
конвейер проходится целиком, но отвечать заглушке нечем, поэтому черновик
приходит с пометкой «оценить вручную» — это и есть штатное поведение при отказе
модели. Готовый черновик без ключа показывает `backend/scripts/demo.py`. Живой
прогон включается переменными `AI_LLM__*` (см. `backend/README.md`).

## Состав репозитория

- `backend/` — Python-сервис (FastAPI + uv): ingest, ревью-агент, детектор ГенИИ.
- `frontend/` — React + Vite, пока на моках.
- `backend/rubrics/` — рубрики как данные: добавить курс = добавить JSON.

## Как это работает

Ссылка на PR → `ingest` собирает провайдеро-независимый `SubmissionBundle` (диффы, а не
тела файлов; полный текст по `content_ref`) → `ai`-слой сводит тексты артефактов
воедино и через `PrivacyGateway` обезличивает ПДн и вызывает LLM: `Review Agent`
ставит вердикты по критериям с обязательными цитатами, `AI-Detection` считает
сигналы ГенИИ → детерминированный код агрегирует баллы, ревьюер утверждает или правит.

Три вещи, которые делают это не обёрткой над чатом:

- **Балл считает код, а не модель.** Модель отвечает по одному критерию и обязана
  приложить цитату; цитата сверяется с текстом файла программно, сумма считается
  агрегатором.
- **Единственный выход к моделям.** Всё уходит через `PrivacyGateway`: скраб ПДн,
  проверка остаточного риска, маршрут, аудит. Правило проверяется тестом, а не
  обещанием.
- **Неполнота видна.** Полного текста файла в сдаче может не быть; такие файлы
  помечены на всём пути — в промпте, в цитатах, в черновике и в ограничениях
  детектора. Вывод «в работе нет обработки ошибок» по одному диффу — некорректный
  вывод, и система это знает.

## Что уже работает, а чего нет

Реализовано: ingest GitHub PR, резолвер `content_ref`, PrivacyGateway с аудитом
стоимости, ревью-агент с валидацией цитат и агрегатором, детектор из четырёх
сигналов, REST поверх всего этого.

Не реализовано: Format Gate (правила уже лежат в рубриках, исполнителя нет),
Rubric Compiler, Assignment Engine, БД и очередь, чат ревьюера с моделью,
экспорт в Sheets. Пороги детектора не калиброваны — данных для калибровки нет.
